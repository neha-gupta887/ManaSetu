# 🚀 Vision

ManaSetu envisions a future where every student has access to intelligent, compassionate, and personalized mental wellness support.

Our mission is to bridge the gap between technology and emotional wellbeing by creating an AI-powered platform that encourages self-awareness, resilience, and healthy daily habits while making mental healthcare more accessible and stigma-free.

# 📖 Overview

ManaSetu is an AI-powered Digital Mental Wellness Platform designed specifically for university students.

The platform combines multiple wellness tools into a single ecosystem, helping students understand their emotions, reduce stress, improve productivity, and develop healthier habits.

Unlike traditional wellness applications, ManaSetu integrates multiple AI agents capable of analyzing mood, stress, sleep patterns, study habits, burnout risk, and emotional wellbeing to provide personalized recommendations.

The platform empowers students through:

- 😊 Mood Tracking
- 📝 Smart Digital Journaling
- 🤖 AI Wellness Companion
- 📈 Emotional Analytics
- 😴 Sleep Analysis
- 📚 Study Planning
- 🔥 Burnout Prediction
- 🚨 Crisis Detection
- 🌬 Guided Breathing Exercises
- 💚 Personalized Wellness Recommendations

# 🎯 Problem Statement

University students frequently experience:

- Academic pressure
- Anxiety and stress
- Homesickness
- Burnout
- Poor sleep
- Lack of emotional support
- Difficulty maintaining healthy habits

Most existing solutions are either expensive, disconnected, or not specifically designed for students.

ManaSetu addresses these challenges by providing an intelligent, student-centric, AI-powered wellness platform.
# 💡 Our Solution

ManaSetu is an AI-powered digital mental wellness platform that helps students proactively understand, manage, and improve their emotional well-being.

Instead of offering isolated wellness features, ManaSetu combines Artificial Intelligence with evidence-based wellness practices to create a single intelligent ecosystem for emotional health.

The platform continuously analyzes user interactions, mood records, journal entries, and wellness patterns to generate personalized recommendations that help students stay mentally healthier, emotionally resilient, and academically focused.

Whether a student is feeling stressed before exams, struggling with sleep, experiencing burnout, or simply wants to reflect on their day, ManaSetu provides timely guidance and actionable wellness suggestions through AI-powered conversations and analytics.

# 🔥 Firebase Setup

ManaSetu uses Firebase as its backend service.

## Enable the following Firebase services

- ✅ Firebase Authentication (Email & Password)
- ✅ Cloud Firestore Database

---

## Configure Firebase

Create the following file:

```text
src/services/firebase.js
```

Configure Firebase using your project credentials.

```javascript
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";
import { getFirestore } from "firebase/firestore";

const firebaseConfig = {
  apiKey: import.meta.env.VITE_FIREBASE_API_KEY,
  authDomain: import.meta.env.VITE_FIREBASE_AUTH_DOMAIN,
  projectId: import.meta.env.VITE_FIREBASE_PROJECT_ID,
  storageBucket: import.meta.env.VITE_FIREBASE_STORAGE_BUCKET,
  messagingSenderId: import.meta.env.VITE_FIREBASE_MESSAGING_SENDER_ID,
  appId: import.meta.env.VITE_FIREBASE_APP_ID,
};

const app = initializeApp(firebaseConfig);

export const auth = getAuth(app);
export const db = getFirestore(app);
```
